# Revisiting the Southern Ocean Pattern Effect
This repository contains information about the cross-model analysis done in "Revisiting the Southern Ocean Pattern Effect" (McSweeney &amp; Rugenstein, 2026). The primary goal of this paper was to revisit Senior &amp Mitchell (2000)'s framework for the role Southern Ocean clouds play in controlling the time-evolution of climate sensitivity. Primarily this code just organizes the analysis of the CMIP6 model output to provide a clear view of how we achieved our results.

# Data
This project relies solely on model output from the Coupled Model Intercomparison Project Phase 6
